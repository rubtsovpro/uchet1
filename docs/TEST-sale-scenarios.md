# Тест · сценарии продаж (26 кейсов)

Чеклист для живых/тестовых сделок **Amo → Учёт №1**.  
Отмечайте ☐ → ☑ после прогона. Рядом пишите номер сделки Amo / id заказа.

**Поля Amo (обязательно до проверки):**
- тип покупателя / ИНН / компания;
- **Канал:** Автосервис | Самовывоз | Отправка;
- **Тип оплаты:** Предоплата | Постоплата;
- **Способ оплаты:** Карта | Наличка | Р/с | Отсрочка | СДЭК Наложка…;
- при Отправке — способ отправки; при Автосервисе — точка СТО.

**На каждом кейсе:**
1. роль покупателя, схема оплаты, пакет документов в Учёте;
2. деньги (ссылка / СБП / р/с / карта / нал / терминал);
3. чеки АТОЛ (см. ожидание);
4. склад: задание → сборка / выдача / отгрузка;
5. документы: счёт / УПД / ЗН;
6. этап Amo после закрытия.

**Чеки:** `2 чека` = аванс→полный · `1 чек` = только полный · `без чека` = р/с / отсрочка / наложка.

## Если нужен ещё возврат

После любого сценария продажи, если клиент возвращает:

1. **Чек возврата** в Учёте (АТОЛ `sell_refund`) — «Возврат» / «Вернуть» у чека. Деньги сам не вернёт.
2. **Деньги клиенту** — вручную в Точке (СБП/карта) или налом / возврат по р/с.
3. В заказе отметить **«Деньги возвращены»**.
4. Если товар вернулся — отдельно **приход на склад** (чек возврата склад не поднимает).

Чек не били — не «возврат», а **чек коррекции** (`/fiscal/correction`).
