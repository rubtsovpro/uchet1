# Стиль бланков СТО · формальный минимальный

Единый вид договоров, заказ-нарядов, приказов и регламентов (Drive DOCX + печать HTML/PDF).  
Без фирменных линий, цветных заливок и декора — только чёрный текст и тонкие чёрные рамки таблиц.

## Токены

| Токен | Значение | Назначение |
|-------|----------|------------|
| `--doc-ink` | `#111111` | Текст и линии |
| `--doc-muted` | `#555555` | Подписи к полям («подпись», «Ф. И. О.») |
| `--doc-font` | `Times New Roman`, Times, serif | |
| `--doc-size` | **минимум `10pt` (факт: `11pt`) везде** · тело/реквизиты `11pt` · заголовок `13–14pt` | |
| `--doc-lh` | `1.2` | |
| Поля A4 | слева `20mm`, справа `15mm`, сверху/снизу `15mm` | |

## Структура

1. Шапка ИП (название, ОГРНИП/ИНН, адреса) — по центру, без линий.
2. Номер документа по центру.
3. Город слева / дата справа.
4. Заголовок по центру.
5. Текст по ширине; разделы `1.` / `1.1.` полужирным.
6. Таблицы — тонкая чёрная рамка, **без** заливки шапки.
7. **Подпись** — в одном блоке с `page-break-inside: avoid` (не отрывать на следующую страницу). При необходимости небольшой отступ сверху, без «висящей» подписи внизу пустой страницы.

## Не делать

- Цветные линии, плашки, фон ячеек, логотипы продукта на бланке.
- Inter / Arial на печати договора.
- Разные поля и кегли в соседних бланках.
