# Бриф ТЗ — Учёт №1 (MRAER)
**Дата:** 17.07.2026  
**Цель ближайшего этапа:** розничные отправки склада без офис-менеджера (Ани), экран заданий на iPad.  
**Не входит в ближайший пакет:** полный Э2–Э5 «под ключ», замена 1С, ИИ-контур целиком.

---

## 1. Принцип

Сначала **рабочий поток** (заказ → оплата → склад → СДЭК/выдача → «Доход»), потом дашборды и «красота».  
Интеграции СДЭК / Точка / АТОЛ / Ozon **не ждут** отдельного этапа подключений — дожимаются в потоке Э1.

### 2.2. Э1 — сделать обязательно (пилот)

| # | Экран | Кто | Что делает |
|---|--------|-----|------------|
| E1-1 | **Задания склада** (iPad / телефон) | Кладовщик | Очередь: № сделки, состав, город, канал, статус. Действия: собрал → упаковал → к выдаче |
| E1-2 | **Карточка задания** | Кладовщик | Строки товара, вес/габариты (если пусто — ввод раз), печать упаковочного листа, ярлык СДЭК |
| E1-3 | **Выдача курьеру** (скан) | Кладовщик | Скан штрихкода листа = «передано», списание |
| E1-4 | **Заказ из сделки** (кнопка) | Менеджер | Amo/сделка → заказ в Учёте: товары, сумма, канал, способ оплаты; **замок суммы** |
| E1-5 | **Оплата заказа** | Клиент / менеджер | Ссылка СБП (приоритет) / карта; статус «Оплачено» авто; чек АТОЛ (по готовности) |
| E1-6 | **Шлюз отгрузки** | Система | «Отдать курьеру» только если оплачено **или** канал постоплаты |
| E1-7 | **СДЭК из Учёта** | Кладовщик / авто | Создание накладной, трек в сделку и в учёт (не только внешний виджет) |
| E1-8 | **Лента «Доход» (зеркало)** | Владелец / офис | Запись реализации в Sheets + просмотр в Учёте почти как таблица (В8) |

**Роли Э1**
- **Кладовщик** — только E1-1…E1-3 (+ печать). Без цен, CRM, настроек.
- **Менеджер** — сделки, заказ, ссылка оплаты. Без полной админки.
- **Владелец / admin** — всё + деньги; 2FA (Э0).
