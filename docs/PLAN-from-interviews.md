# План реализации по итогам интервью с сотрудниками

**Проект:** Учёт №1  
**Контур Заказчика:** Пневмоподвеска  
**Рабочие адреса:** `1c.pnevmopodveska1.ru`, `uchetn1.ru`  
**Назначение документа:** перечень работ по автоматизации процессов, выявленных в интервью; контрольные списки по разделам системы.  
**Отметка выполнения:** `[ ]` — не выполнено; `[x]` — выполнено.

---

## 1. Общие положения

1.1. Документ фиксирует состав и очерёдность внедрения функций системы «Учёт №1» на основании описания текущих процессов сотрудниками.  
1.2. Цель внедрения — исключить ручные посреднические операции (переписка в мессенджерах, вспомогательные таблицы, дублирование ввода), обеспечить сквозную связь сделки, заказа, оплаты, складского задания и первичных документов.  
1.3. Распределение рабочих мест: менеджер по продажам — AmoCRM; кладовщик — рабочий экран сборки; сотрудник приёмки СТО — рабочий экран приёмки; учёт заказов, документов и заданий — система «Учёт №1».  
1.4. Приоритет первого этапа обусловлен прекращением функции офис-менеджера: необходимо обеспечить передачу заказа на склад и отражение дохода без указанной роли.

---

## 2. Очерёдность внедрения

**Этап внедрения** — завершённый объём работ, подлежащий приёмке на реальных операциях.  
**Раздел** (обозначение §) — тематический блок контрольного списка. Номер пункта раздела (например, 5.1) не совпадает с номером этапа внедрения.

| Этап | Ориентировочный срок | Состав результата | Основание |
|------|----------------------|-------------------|-----------|
| Этап 1 | 2–3 недели | Продажа с предоплатой и самовывозом; формирование складского задания; сборка; оформление отправления СДЭК; автоматическая привязка оплаты к сделке; перевод сделки в статус дохода без участия офис-менеджера | Ежедневный контур продаж и склада |
| Этап 2 | дополнительно 2 недели | Счёт на оплату и карточка контрагента по ИНН; УПД с автоматической нумерацией; связь «клиент — заказ — оплата — УПД»; оплата на СТО на основании закрытого заказ-наряда | Первичные и налоговые документы |
| Этап 3 | дополнительно 2–3 недели | Календарь записи на СТО; статусы визита; запрос перемещения деталей; рабочий экран приёмки | Исключение внешней таблицы записи на СТО |
| Этап 4 | дополнительно 3–4 недели | Расчёт потребности; заказ поставщику; учёт невыполненных отгрузок; задолженность; фиксация брака с вложениями | Исключение разрозненных таблиц закупщика |
| Сопутствующие работы | в ходе этапов 2–4 | Разделение номенклатуры «новая / восстановленная»; настройка прав доступа | Достоверность ожидаемых поставок и ограничение доступа к закупочным ценам |

Этап 1 охватывает соответствующие пункты разделов «Продажи», «Склад», «Доставка», «Оплаты». Этап 3 — раздел «СТО». Этап 4 — раздел «Закупки».

## 3. Раздел: CRM и сделки (AmoCRM и Учёт №1)

Основание: интервью по продажам и приёмке — первичная обработка обращения, контроль заполнения, отражение дохода.

### 3.1. Карточка сделки и обязательные реквизиты
- [ ] Утверждён перечень обязательных реквизитов: филиал, этап, канал реализации, способ получения, направление (розничная продажа / СТО / партнёр / самовывоз)
- [ ] Проверка реквизитов до отправки сделки в учётную систему; при отсутствии — отказ с указанием недостающих полей
- [ ] Запрет отправки сделки при незаполненных филиале, этапе либо данных отправления (для канала отправки)
- [ ] Отображение в карточке Учёта №1: идентификатор AmoCRM, воронка, этап, контакт, сумма, канал, филиал
- [ ] Табличный список сделок по всем воронкам с фильтром по воронке и признаку передачи в учёт

### 3.2. Этапы сделки и отражение дохода
- [ ] Изменение этапа сделки на доске с синхронизацией в AmoCRM (реализовано)
- [ ] Автоматическая смена этапа на доходный при выполнении условий «отгружено (или выдано) и оплачено»
- [ ] Исключение зависимости процесса от таблицы «Приход–расход» и роли офис-менеджера
- [ ] Журнал изменений этапа (пользователь, дата и время)

### 3.3. Задачи и уведомления
- [ ] Автоматическая постановка задачи контроля самовывоза при выборе соответствующего канала
- [ ] Уведомление менеджеру о статусах: собрано, упаковано, отправлено, выдано
- [ ] Уведомление приёмке о новой записи на СТО и о прибытии клиента в слот

### 3.4. Действия из AmoCRM без перехода в 1С
- [ ] Создание и открытие заказа в Учёте №1
- [ ] Формирование ссылки на оплату
- [ ] Формирование счёта на оплату (PDF)
- [ ] Передача заказа на склад либо создание отправления СДЭК
- [ ] Формирование УПД по запросу юридического лица
- [ ] Запись клиента на СТО (выбор слота)

## 4. Раздел: продажи

Основание: предоплата, партнёрские продажи, самовывоз, закрытие продажи.

### 4.1. Заказ покупателя на основании сделки
- [ ] Создание заказа покупателя в Учёте №1 на основании сделки AmoCRM
- [ ] Вид заказа: розничная продажа / СТО / партнёр
- [ ] Перенос позиций из виджета заказа в строки заказа покупателя
- [ ] Резервирование позиций до указанной даты (визит СТО, самовывоз)
- [ ] Статусы заказа: черновик → ожидает оплаты → оплачен → передан на склад → завершён / отменён

### 4.2. Продажа с полной предоплатой
- [ ] Формирование ссылки на оплату (СБП) из заказа одной операцией
- [ ] Направление ссылки клиенту через чат AmoCRM либо SMS без копирования из 1С
- [ ] Автоматическая привязка поступившей оплаты к сделке и заказу
- [ ] Отражение статуса «оплачено» в Учёте №1 и в AmoCRM без ручной обработки уведомлений мессенджера
- [ ] Передача на склад допускается только после подтверждения оплаты (для схемы предоплаты)

### 4.3. Самовывоз
- [ ] При канале «самовывоз» формируется складское задание на выдачу в зону выдачи
- [ ] Очередь самовывоза на экране приёмки (без размещения в таблице записи на СТО без времени)
- [ ] Поиск заказа по номеру и подтверждение выдачи сотрудником приёмки
- [ ] Закрытие операции: списание (расходная накладная) и смена этапа сделки в AmoCRM

### 4.4. Партнёрская продажа (юридическое лицо)
- [ ] Поиск контрагента по ИНН в Учёте №1
- [ ] Создание карточки контрагента: организационно-правовая форма, ИНН, телефон, электронная почта, адрес, расчётный счёт (заполнение реквизитов по ИНН через сервис проверки)
- [ ] Формирование счёта на оплату в PDF (с печатью и подписью либо без них)
- [ ] Направление счёта в чат AmoCRM одной операцией
- [ ] Возможность нескольких УПД по одной сделке

### 4.5. Документы продажи
- [ ] Формирование комплекта документов из сделки: счёт, заказ-наряд, УПД
- [ ] Связь расходной накладной (реализации) с заказом и оплатой
- [ ] Печать и выгрузка PDF без использования 1С
- [ ] Непрерывная автоматическая нумерация документов без ручного присвоения номера бухгалтером

## 5. Раздел: склад

Основание: интервью со сотрудником склада — сборка, перемещения, приёмка поставки, инвентаризация.

### 5.1. Складские задания
- [ ] Автоматическое создание задания при оплаченном заказе либо при статусе «передан на склад»
- [ ] Очередь на экране сборки: новое → в сборке → упаковано → отправлено / выдано
- [ ] Карточка задания: позиции, канал отгрузки, сделка, сумма
- [ ] Уведомление кладовщику о новом задании штатными средствами системы
- [ ] Уведомление менеджеру об изменении статуса задания
- [ ] Исключение бумажной расходной накладной как единственного сигнала складу

### 5.2. Сборка и упаковка
- [ ] Отметка собранных позиций (сканирование либо подтверждение по строкам)
- [ ] Ввод веса и габаритов в карточке задания
- [ ] Печать расходной накладной и этикетки из задания
- [ ] Статус «упаковано» — готовность к передаче курьеру либо к выдаче
- [ ] Статус «отправлено» после передачи отправления курьеру

### 5.3. Перемещения между складами
- [ ] Документ «запрос на перемещение» создаётся сотрудником СТО (приёмки)
- [ ] Проведение перемещения выполняется только сотрудником склада
- [ ] Формирование задания кладовщику на доставку в зону СТО (приёмки)
- [ ] Связь документов: заказ покупателя → запрос → перемещение → факт исполнения
- [ ] Запрет проведения перемещения без утверждённого запроса (права доступа)

### 5.4. Приёмка поставки от поставщика
- [ ] Перечень ожидаемых поставок (товар в пути)
- [ ] Сверка фактического состава с заказом: количество, артикул, маркировка
- [ ] Фиксация расхождений: недостача, пересорт, брак, повреждение
- [ ] Прикрепление фото- и видеоматериалов к карточке приёмки
- [ ] Согласование с закупщиком до проведения приходной накладной
- [ ] Проведение приходной накладной только после согласования
- [ ] Учёт размещения на складе (склад / зона; адресное хранение — последующая очередь)

### 5.5. Инвентаризация и пересорт
- [ ] Задание на пересчёт (склад, зона, выборка номенклатуры)
- [ ] Ввод фактического количества
- [ ] Журнал расхождений
- [ ] Утверждение корректировки уполномоченным лицом
- [ ] Документ пересорта с указанием причины
- [ ] История корректировок по номенклатурной позиции

## 6. Раздел: доставка (СДЭК)

Основание: оформление отправления со стороны менеджера и склада.

### 6.1. Оформление из складского задания
- [ ] Создание отправления СДЭК после указания веса и габаритов
- [ ] Выбор тарифа, пункта выдачи, способа оплаты доставки
- [ ] Для предоплаченного заказа — отключение взимания стоимости товара при вручении
- [ ] Сохранение трек-номера в задании и в сделке AmoCRM
- [ ] Печать ярлыка и накладной с кодом идентификации
- [ ] Обновление статусов доставки в задании

### 6.2. Оформление из сделки менеджером
- [ ] Утверждён основной сценарий: оформление отправления выполняет склад после сборки; менеджер передаёт заказ на склад
- [ ] Передача трек-номера в карточку сделки AmoCRM
- [ ] Контроль отсутствия дублирующих отправлений по одному заказу

### 6.3. Каналы отгрузки
- [ ] Единый справочник каналов: СДЭК, самовывоз, иные способы
- [ ] Фильтрация очереди сборки по каналу

## 7. Раздел: оплаты и бухгалтерия

Основание: оплата, доход, УПД, взаимодействие с удалённой бухгалтерией.

### 7.1. Оплаты по сделкам
- [ ] Формирование ссылки на оплату (СБП) из заказа
- [ ] Автоматическое получение статуса оплаты от банка и установка признака «оплачено» на заказе и сделке
- [ ] Исключение ручной привязки оплаты через бот мессенджера
- [ ] Фиксация способа оплаты (СБП, карта, терминал, счёт)
- [ ] Учёт частичных оплат отдельными строками (при необходимости для партнёров)

### 7.2. Отражение дохода
- [ ] Автоматическая регистрация дохода при завершении отгрузки либо выдачи при наличии оплаты
- [ ] Синхронизация этапа сделки в AmoCRM без ручной операции «отправить в доход»
- [ ] Единый источник данных для управленческой отчётности

### 7.3. УПД и счета-фактуры
- [ ] Формирование УПД из реализации (заказа) одной операцией
- [ ] Автоматическая нумерация УПД и счетов-фактур
- [ ] Привязка документов: контрагент — заказ — оплата — УПД без отдельного запроса номера у бухгалтера
- [ ] Возможность нескольких УПД по одной сделке
- [ ] Передача сведений удалённой бухгалтерии по каждой операции
- [ ] Запрет объединения поступлений разных контрагентов в один налоговый документ

### 7.4. Сверки
- [ ] Формирование акта сверки по контрагенту за период
- [ ] Очередь контроля: оплата без оформленного УПД
- [ ] Оплата на СТО на основании закрытого заказ-наряда (QR-код, терминал, карта)

### 7.5. Оплата на СТО
- [ ] Основанием оплаты является закрытый заказ-наряд (дополнительная расходная накладная не является обязательным шагом)
- [ ] Выдача чека либо ссылки на оплату из заказ-наряда
- [ ] Привязка оплаты к сделке и закрытие этапа

## 8. Раздел: СТО (запись, приёмка, работы)

Основание: запись на сервис, диагностика, перемещение деталей, заказ-наряд.

### 8.1. Расписание
- [ ] Справочник интервалов записи: 10:00, 13:00, 16:00 (с учётом филиала и подъёмника)
- [ ] Календарь свободных и занятых слотов в Учёте №1
- [ ] Создание записи из AmoCRM либо из карточки сделки
- [ ] Реквизиты записи: автомобиль, государственный номер либо телефон, номер сделки
- [ ] Направление клиенту подтверждения записи, контактных данных и инструкции о проезде через AmoCRM
- [ ] Исключение внешней таблицы «Запись на СТО» как основного источника данных

### 8.2. Статусы визита
- [ ] Цепочка статусов: записан → прибыл → в работе → готов → выдан
- [ ] Отображение статусов на экране приёмки
- [ ] Постановка задачи приёмке в AmoCRM при создании записи

### 8.3. Работы и материалы
- [ ] Заказ-наряд: услуги и товары отдельными строками
- [ ] Добавление работ и деталей в ходе диагностики
- [ ] Фиксация согласования дополнительных работ с клиентом
- [ ] Рекомендации клиенту в заказ-наряде
- [ ] Резерв деталей до даты визита в заказе покупателя

### 8.4. Обеспечение деталями с основного склада
- [ ] При добавлении детали — автоматическое создание запроса на перемещение
- [ ] Отображение запроса в очереди склада
- [ ] Фиксация факта перемещения в зону приёмки
- [ ] Исключение передачи номера перемещения через мессенджер

### 8.5. Закрытие заказ-наряда
- [ ] Печать заказ-наряда
- [ ] При закрытии: списание товаров и переход к оплате
- [ ] Выдача чека клиенту
- [ ] Установка успешного этапа сделки после оплаты

### 8.6. Рабочий экран приёмки
- [ ] Очередь дня по слотам
- [ ] Карточка визита: сделка, автомобиль, заказ-наряд, детали
- [ ] Операции: отметка прибытия, запрос детали, закрытие, оплата
- [ ] Самовывоз в общей очереди с отдельным типом операции

## 9. Раздел: закупки

Основание: интервью с сотрудником отдела закупки.

### 9.1. Расчёт потребности
- [ ] Сводка по номенклатуре: продажи за период, упущенные продажи, остаток, товар в пути, невыполненные отгрузки поставщика, товар в производстве
- [ ] Параметры «запас в месяцах» и срок поставки
- [ ] Учёт кратности упаковки и условий скидки за объём
- [ ] Обязательное подтверждение закупщиком до размещения заказа (без автоматического заказа без участия специалиста)
- [ ] Выгрузка проекта заказа в файл для переходного периода

### 9.2. Ассортиментная матрица
- [ ] Соответствие внутреннего артикула артикулам поставщиков
- [ ] Закупочные цены поставщиков (доступ только уполномоченным ролям)
- [ ] Основной поставщик по умолчанию
- [ ] Признак взаимозаменяемости и предпочтительной позиции к закупке
- [ ] Признак обязательного наличия на складе

### 9.3. Заказ поставщику
- [ ] Формирование заказа: внутренний артикул, артикул поставщика, количество, цена
- [ ] Статусы: черновик → отправлен → получено подтверждение (proforma) → подтверждён → в производстве
- [ ] Ввод данных подтверждения поставщика (количество и цены)
- [ ] Предупреждение при существенном отклонении цены от прайса
- [ ] Подтверждение запуска заказа в работу закупщиком

### 9.4. Невыполненные отгрузки и партии
- [ ] Учёт подтверждённых, но не отгруженных позиций; объединение остатков нескольких заказов
- [ ] Учёт частичной отгрузки по счёту поставщика (invoice) с уменьшением остатка к отгрузке
- [ ] Партия «в пути» с составом по счёту поставщика
- [ ] Расчёт себестоимости с доставкой (курс и коэффициенты)
- [ ] Связь партии с приходной накладной

### 9.5. Задолженность и расчёты с поставщиками
- [ ] Баланс по поставщику: увеличение по счетам поставщика, уменьшение по оплатам и кредитовым документам
- [ ] Условия оплаты: полная предоплата, частичная предоплата, оплата после получения, отсрочка
- [ ] Платёжный календарь: общая, предстоящая и просроченная задолженность
- [ ] Валюта документа (китайский юань / российский рубль)
- [ ] Планирование дат платежей

### 9.6. Брак и рекламации
- [ ] Реестр: партия, артикул, количество, причина
- [ ] Ссылки на фото- и видеоматериалы приёмки
- [ ] Фиксация подтверждённой поставщиком компенсации
- [ ] Отражение компенсации в балансе (кредитовый документ либо скидка в следующем счёте)
- [ ] Статистика качества по поставщику и партии (сроки, доля брака)

### 9.7. Маркировка для приёмки
- [ ] Требования к наклейке поставщика (внутренний код)

- [ ] Порядок присвоения новых внутренних кодов и права на операцию

## 11. Права доступа

- [ ] Роли: менеджер по продажам, кладовщик, приёмка СТО, закупщик, бухгалтер (просмотр), администратор
- [ ] Доступ к закупочным ценам поставщиков — только закупщик и администратор
- [ ] Проведение перемещений — только склад; создание запросов — СТО (приёмка)
- [ ] Бухгалтер: очередь УПД и сверки без изменения этапов продаж
- [ ] Детализация прав до отдельных полей матрицы закупок — после внедрения базовых ролей

---

## 12. Критерии приёмки по ролям

**Менеджер по продажам:** оформление сделки, оплаты и счёта, передача на склад либо на СТО без переписки со складом в мессенджере и без участия офис-менеджера.  
**Кладовщик:** работа по очереди заданий, сборка, оформление СДЭК, исполнение перемещений по запросам.  
**Приёмка СТО:** календарь дня, заказ-наряд, запрос деталей, выдача, оплата.  
**Закупщик:** расчёт потребности, заказ поставщику, учёт невыполненных отгрузок, задолженность, брак.  
**Бухгалтерия:** УПД по каждой оплате, акты сверки, отсутствие объединения операций разных контрагентов.
