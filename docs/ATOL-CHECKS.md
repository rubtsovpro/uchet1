# Чеки АТОЛ и возвраты

Онлайн-касса **АТОЛ Online v5** (ИП Безматерных, группа из кабинета интегратора).

Настройки: **Настройки → АТОЛ** (`/settings/atol`).  
Адрес расчётов в чеке: `https://pay.pnevmopodveska1.ru`.

## Типы чеков

| Кнопка на сделке | kind API | АТОЛ | Когда |
|------------------|----------|------|--------|
| 1 · предоплата | `advance` | `sell` | После оплаты по СБП/карте |
| 2 · полный | `full` | `sell` | При выдаче / полном расчёте |
| Возврат | `refund` / `refund_advance` | **`sell_refund`** | Возврат покупателю |

API: `POST /api/crm/deals/{id}/fiscal/{kind}`  
Тело: `{ "send": true, "parent_receipt_id": "…" }` — `parent_receipt_id` опционален (для возврата по конкретному чеку).

## Возврат — что делает система

1. Берёт исходный чек (полный, иначе предоплату) или указанный `parent_receipt_id`.
2. Собирает чек возврата с теми же позициями/суммой.
3. Отправляет в АТОЛ **`/{group}/sell_refund`** → документ уходит в **ОФД**.
4. Пишет запись в `fiscal_receipts` (`kind=refund|refund_advance`, связь `parent_receipt_id`).

На карточке сделки: кнопка **«Возврат»** и **«Вернуть»** в строке чека.

## Что возврат НЕ делает

- **Не** возвращает деньги на карту / СБП автоматически.  
  Фискальный чек возврата ≠ платёж в Точке. Деньги — вручную в кабинете Точки / банке.
- **Не** снимает товар со склада «назад» сам по себе — складской возврат прихода/оприходование при необходимости отдельно.

## ОФД

Отдельной интеграции с ОФД нет: АТОЛ Online сам передаёт чеки (продажа и возврат) оператору фискальных данных. Смотрите статусы в кабинете АТОЛ / ОФД по `atol_uuid`.

## Публичная оплата

Ссылки клиенту: `https://pay.pnevmopodveska1.ru/pay/{token}`  
(пока DNS `pay` не поднят — работает и `https://1c.pnevmopodveska1.ru/pay/{token}`).
