## Легенда

| Статус в Учёте №1 | Значение |
|-------------------|----------|
| **есть** | Рабочий аналог в WMS / смежном контуре под `1c.*` или осознанный канал (amo1c, bank) |
| **частично** | Данные/заготовка есть; UI или полный сценарий не закрыт |
| **нет** | В Учёте №1 отсутствует; остаётся в 1С или в бэклоге |

| Приоритет переноса | Значение |
|--------------------|----------|
| **P0** | Ближайшие спринты (Э0–Э1) |
| **P1** | Волна 2–3 (закупки UI, СДЭК, деньги, аналитика) |
| **P2** | СТО / МП / производство / адресный склад |
| **P3** | Вне scope v1 или сознательно остаётся в 1С/SaaS |

Повторяющиеся пункты (Номенклатура, Отчеты, Доп. обработки) учитываются **в каждом разделе**, где видны на скрине — как в UI 1С.

### 8.1. Валюты и курсы (скриншоты карточек УНФ, 19.07.2026)

Путь в 1С: **Деньги → справочник «Валюты»** (карточки также открываются из списка валют; в шапке УНФ — живые курсы).  
В Учёте №1 **есть** справочник `/currencies` (RUB/USD/RMB + курсы ЦБ РФ). Печать/valuation по умолчанию ещё RUB; поле `currency` у Точки — проброс строки банка.

| Код | Наименование | Цифровой код | Символ | Курс в карточке 1С | Факт шапки 19.07 |
|-----|--------------|-------------:|--------|--------------------|------------------|
| RUB | Российский рубль | 643 | ₽ | вводится вручную | (нац. валюта) |
| USD | Доллар США | 840 | $ | загружается из Интернета | **78,40** |
| RMB | Китайский юань | 156 | ¥ | загружается из Интернета | **11,56** |

Карточка валюты УНФ (вкладки **Основное** / **Курсы валют**):

| Режим курса | Назначение |
|-------------|------------|
| вводится вручную | Как у RUB |
| загружается из Интернета | Как у USD / RMB |
| связан с курсом другой валюты | База + наценка % |
| рассчитывается по формуле | Произвольная формула |
| + Параметры прописи валюты | Сумма прописью в печатных формах |

**Scope Учёт №1 (бэклог, не в фикс-месяце без оценки):** справочник валют (ISO/цифровой/символ) + история курсов на дату + источник (ручной / ЦБ или аналог «из Интернета») + использование в закупках/продажах/деньгах. Приоритет **P1–P2** (закупки RMB/USD), не P3. Оценка — см. смету опций и §8 реализация.
