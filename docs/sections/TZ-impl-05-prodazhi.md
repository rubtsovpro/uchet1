# §5. Продажи — что надо для реализации

**Проект:** Учёт №1 · live `1c.pnevmopodveska1.ru`  
**Раздел каркаса:** §5  
**Оценка остатка:** L · 50–90 чел-дней

---

## 1. Цель раздела

Юр: счёт → оплата → УПД/СФ/расходная. Физ: заказ → оплата → два чека АТОЛ → списание. Возвраты и анализ продаж.

---

## 2. Уже есть в Учёте №1

- Счета / УПД / PDF / нумерация (`sales-docs`, pdfkit).
- Расходные из OData sync.
- АТОЛ: payload двух чеков в режиме prepared.

---

## 3. Можем сделать сейчас

(1–2 спринта, без новых внешних блокеров)

- Розничный конвейер Э1: заказ, оплата, шлюз отгрузки, списание со склада.
- Сценарий списания галочками с остатка прихода.
- Включить АТОЛ live при credentials.

---

## 4. Что надо для полной реализации

- Полный пакет юр. с НДС; DaData в карточке контрагента.
- Контроль ОФД (когда/кому ушли чеки), балансы АТОЛ.
- Возвраты; «забытые продажи»; потенциал реализации.
- Заказ-наряды как документ продаж (связка с §9).
- Приёмка: юр — счёт+УПД+списание; физ — 2 чека+списание; предоплата не уходит без оплаты.

---

## 5. Блокеры / ждём

- АТОЛ live / договор и credentials.
- Часть сценариев СТО — §9.
