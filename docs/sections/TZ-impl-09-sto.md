# §9. Работы / СТО — что надо для реализации

**Проект:** Учёт №1 · live `1c.pnevmopodveska1.ru`  
**Раздел каркаса:** §9  
**Оценка остатка:** L · 60–100 чел-дней

---

## 1. Цель раздела

Один экран мастера-приёмщика: запись, подъёмники, работы, запчасти, касса, ЗП механиков.

---

## 2. Уже есть в Учёте №1

- Частичная логика в смежных контурах amo1c/bank (не ядро WMS).
- Списание со склада из общих сценариев — переиспользуемо.

---

## 3. Можем сделать сейчас

(1–2 спринта, без новых внешних блокеров)

- Не в ближайших 1–2 спринтах Э1 (кроме переиспользования списания).
- Уточнить на созвоне модель ЗП/МДС/KPI.

---

## 4. Что надо для полной реализации

- E2-1 экран мастера: календарь, статусы Записан→Выдано, загрузка подъёмников.
- Номенклатура работ; заказ-наряды.
- E2-2 расчёт/касса СТО (нал/терминал/QR + чек).
- E2-3 ЗП механиков (% от работ).
- Приёмка: смена без «тетрадки» на выдаче; касса бьёт чек; ЗП считается из ЗН.

---

## 5. Блокеры / ждём
