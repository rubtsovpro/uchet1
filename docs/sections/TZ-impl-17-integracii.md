---

## 1. Цель раздела

Рабочие каналы: 1С, Amo, Точка/СБП, АТОЛ, СДЭК, Sheets, Telegram, ИИ, DaData, Roistat — без двойного учёта ответственности.

---

## 2. Уже есть в Учёте №1

- 1С OData/HS + docs-sync — live.
- Amo через amo1c.
- Точка/СБП через bank; Sheets «Доход».
- АТОЛ prepared; СДЭК виджет; S3 медиа.

---

## 3. Можем сделать сейчас

(1–2 спринта, без новых внешних блокеров)

- Дожим в потоке Э1: СБП, Sheets запись, АТОЛ при ключе, виджет СДЭК.
- Секреты/credentials на проде по чеклисту.

---

## 4. Что надо для полной реализации

- Native СДЭК; АТОЛ ОФД UI; cutover bank.
- DaData; Telegram-алерты остатков.
- ИИ read-API / webhooks — граница продукта.
- Roistat/Яндекс — по §16.
- Приёмка: каждая интеграция — smoke + ответственный + rollback.

## 5. Блокеры / ждём

- Публикация недостающих документов 1С.
