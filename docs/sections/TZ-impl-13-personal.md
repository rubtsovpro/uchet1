# §13. Персонал — что надо для реализации

**Проект:** Учёт №1 · live `1c.pnevmopodveska1.ru`  
**Раздел каркаса:** §13  
**Оценка остатка:** S–M · 15–30 чел-дней

---

## 1. Цель раздела

Сотрудники, RBAC, auth, 2FA admin, графики для СТО.

---

## 2. Уже есть в Учёте №1

- Auth / сессии / роли; cookie `wms_sid`.
- Presence (кто онлайн).
- Staff sync из Amo.
- Audit log действий.

---

## 3. Можем сделать сейчас

(1–2 спринта, без новых внешних блокеров)

- Роль «кладовщик» в правах (Э0/Э1).
- Матрица: менеджер / владелец.

---

## 4. Что надо для полной реализации

- 2FA/MFA admin (TOTP) + политика исключений shared iPad.
- Графики работы / загрузка специалистов (со §9).
- Ретеншн audit ≥ 1 год (DoD).
- Приёмка: admin без 2FA не входит; кладовщик не видит цены/деньги.

---

## 5. Блокеры / ждём

- Политика исключений iPad — иначе 2FA ломает смену.

---

## 6. Зависимости

См. сводную таблицу и волны на вкладке «Роадмап · можем сейчас». Детали смежных разделов — вкладки § соседних номеров.

## 7. Чеклист меню 1С УНФ (Персонал)

Полная карта: вкладка «Карта 1С УНФ → Учёт №1».

| Пункт 1С | Учёт №1 | Приоритет |
|----------|---------|-----------|
| Сотрудники | частично | P0 |
| Кадры (приём / перемещения / увольнения / ПДн) | нет | P3 |
| Зарплата / начисления / ведомости / табели | нет | P2–P3 |
| Графики / смены / виды времени | нет | P2–P3 |
| Премии / показатели / правила | нет | P3 |
| Роль кладовщик / 2FA (WMS) | есть / в работе | P0 |
