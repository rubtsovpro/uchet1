# §4. Закупки / приход — что надо для реализации

**Проект:** Учёт №1 · live `1c.pnevmopodveska1.ru`  
**Раздел каркаса:** §4  
**Оценка остатка:** M–L · 40–80 чел-дней

---

## 1. Цель раздела

Понятная видимость закупок: документ прихода, поставщик, закупочная цена по строкам, история товара; далее — заказы поставщикам и сверки.

---

## 2. Уже есть в Учёте №1

- OData `Document_ПриходнаяНакладная` (+ Запасы) синкается `docs-sync`.
- Остатки из HS Get/Rests (отдельно от пересчёта приходными).
- Поле ГТД в OData (`НомерГТД_Key`) — маппинг дотянуть.

---

## 3. Можем сделать сейчас

(1–2 спринта, без новых внешних блокеров)

- UI список/карточка приходной: поставщик, строки, цена/сумма.
- Показ в истории товара.
- Дотянуть `$select` / срок ожидания поставщика (реквизит в Учёте при отсутствии в 1С).
- Маппинг ГТД в sync + UI.

---

## 4. Что надо для полной реализации

- Заказы поставщикам, счета полученные, сверки, корректировки долга.
- Прайс-листы поставщиков, расчёт потребностей + алерты.
- Переработка / документы переработчиков.
- Канал: публикация OData / HS / ручной ввод.
- Приёмка: кладовщик/закупщик видит «кто/по чём/каким документом» без «голого» OData.

---

## 5. Блокеры / ждём

- Заказы поставщикам и счета полученные **не опубликованы** в OData — ждём 1С/HS.
