# §3. CRM / контрагенты — что надо для реализации

**Проект:** Учёт №1 · live `1c.pnevmopodveska1.ru`  
**Раздел каркаса:** §3  
**Оценка остатка:** M · 25–40 чел-дней

---

## 1. Цель раздела

Контрагенты юр/физ, сделки и воронки Amo в Учёте; заказ из сделки с замком суммы; обогащение реквизитов.

---

## 2. Уже есть в Учёте №1

- Сделки / воронки через amo1c CLI → WMS.
- Сотрудники Amo (staff sync).
- Базовый справочник контрагентов.
- Платежи СБП из контура сделки (прокси bank).

---

## 3. Можем сделать сейчас

(1–2 спринта, без новых внешних блокеров)

- E1-4: кнопка «Заказ из сделки» + замок суммы.
- Привязка контрагента к заказу/документам продажи.
- Уточнить/встроить DaData (в ТЗ есть, в ядре не найдено).

---

## 4. Что надо для полной реализации

- События CRM / задания CRM в Учёте.
- Транскрибация разговоров — граница с ai-контуром.
- Автозагрузка контрагентов из Amo + дедуп телефонов.
- Приёмка: сделка → заказ с фиксированной суммой; смена суммы только с правом.

---

## 5. Блокеры / ждём

- Транскрибация/ИИ — отдельные хосты; не ядро WMS v1 без решения границы.

---
