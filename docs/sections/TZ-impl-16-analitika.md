## 1. Цель раздела

Воронка, звонки+сделки+деньги, атрибуция; управленка «Отчёт МСК»; без обязательного отключения внешнего Roistat.

- Модуль в плане, не в прод-потоке аналитики.

(1–2 спринта, без новых внешних блокеров)

## 4. Что надо для полной реализации

- A1: синк звонков Amo → журнал; экраны `/analytics/*`.
- Связка источников/воронок; нормализация телефонов.
- «Отчёт МСК» День/Месяц (Э5).
- Экспорт CSV/Sheets.
- Полный свой Roistat (UTM, динамический коллтрекинг) — отдельная смета ≥ ноя 2026.
- Приёмка A1: звонок виден в разрезе сделки; дашборд руководителя не пустой.

---

## 5. Блокеры / ждём

- Стабильный Э1.
- Полный Roistat — вне v1; внешний не отключать.
- Прямой Megafon CDR — сознательно не v1.

| Пункт 1С | Учёт №1 | Приоритет |
|----------|---------|-----------|
| KPI Главное (продажи, долги, активы) | частично / нет | P1–P2 |
| Воронка продаж | частично | P0 |
| Динамика продаж / структура списания | нет | P2 |
