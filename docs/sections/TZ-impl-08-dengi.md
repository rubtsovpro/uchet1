# §8. Деньги — что надо для реализации

**Проект:** Учёт №1 · live `1c.pnevmopodveska1.ru`  
**Раздел каркаса:** §8  
**Оценка остатка:** M–L · 40–70 чел-дней

---

## 1. Цель раздела

Банк Точка / СБП / касса / дебиторка в одном контуре Учёта; платежи только с одобрения владельца.

---

## 2. Уже есть в Учёте №1

- React `/money/*` → overview Точка через bank-прокси.
- Создание СБП QR из сделки (endpoint пока на bank.*).
- Зеркало «Доход» Sheets в `/income`.
- АТОЛ prepared в денежном/продажном потоке.

---

## 3. Можем сделать сейчас

(1–2 спринта, без новых внешних блокеров)

- Дожим СБП-ссылки на карточке заказа (Э1).
- Запись реализации в «Доход» без ручного ввода.
- Явная фиксация: исходящие платежи — только approve владельца.

---

## 4. Что надо для полной реализации

- Cutover bank.* → 1c.* (callbacks, DNS, cookie origin).
- Касса / POS (железо).
- Платёжные поручения; единая дебиторка / партнёрские балансы.
- **Валюты и курсы** (аналог 1С Деньги → Валюты): справочник RUB/USD/RMB + история курсов + загрузка «из Интернета» / ручной ввод; сейчас в Учёте только hardcode RUB в печати и valuation. Подробности — карта §8.1. Оценка S–M (см. смету опций).
- Приёмка: оплата заказа меняет статус авто; overview доступен под 1c.*.

---

## 5. Блокеры / ждём

- Cutover — план URL/webhook.
- POS — железо + ТЗ.
- partner.* — решение встроить vs оставить.

## 7. Чеклист меню 1С УНФ (Деньги)

Полная карта: вкладка «Карта 1С УНФ → Учёт №1».

| Пункт 1С | Учёт №1 | Приоритет |
|----------|---------|-----------|
| Банк и касса / документы банка | частично | P1 |
| ПП / поступления / расходы со счёта | нет / частично | P1–P2 |
| Касса / авансы / кассовая книга | нет | P2–P3 |
| Эквайринг (карты) | нет | P2 |
| Кредиты и займы | нет | P3 |
| Планирование / платёжный календарь | нет | P2–P3 |
| Валюты (справочник + курсы) | нет | P1–P2 |
| Кассы / статьи ДДС | нет | P2–P3 |
| СБП из сделки + UI Деньги/Доход | есть | P0 |
